FREQUENTLY ASKED QUESTIONS

Got Questions? We've Got Answers

Can I install the generated Android APK on any smartphone?

Yes! The generated Android APK is a complete 72 MB standalone application container with its own WebView runtime. You can download and install it on any Android device running Android 7.0 (Nougat) through Android 15+ without needing Google Play.

How does iOS installation work without the App Store?

WebToApp generates a valid Apple WebClip Configuration Profile (.mobileconfig). When downloaded in Safari, iOS asks you to install the profile, adding a full-screen, dedicated icon to your Home Screen with zero Safari browser chrome.

Do I need to sign up to test and create apps?

Creating an account takes less than 10 seconds and allows your generated apps to be backed up to the cloud so you never lose your download links and custom configurations.
